# Screenshot Scout Go SDK

The official Go SDK for the Screenshot Scout API.

This repository currently contains the minimal local package scaffold. The API client, focused tests, and usage examples are added in the implementation step.

## Requirements

- Go 1.25 or later

The initial support policy covers the latest two stable Go releases. The supported versions are rechecked before publication.

## Module

`github.com/screenshotscout/screenshotscout-go`

## Development

Run the standard Go checks from the repository root:

```sh
go test ./...
go vet ./...
```
